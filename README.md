# Прогнозирование количества наград "Оскар" у актёров
## Описание проекта

Построение регрессионной модели, которая предсказывает, сколько премий «Оскар» получил актёр, зная:
- количество номинаций на **Оскар**,
- количество номинаций на **BAFTA**,
- количество номинаций на **«Золотой глобус»**,
- количество фактических побед **BAFTA**,
- количество фактических побед **«Золотой глобус»**.

Проект включает:
- обучение и сравнение двух моделей (линейная регрессия, случайный лес),
- выбор лучшей модели по кросс-валидации,
- сохранение модели в `best_actor_award_predictor.pkl`,
- веб-интерфейс на **Streamlit** для демонстрации предсказаний.

## Данные

Источник: `Top 100 Greatest Hollywood Actors of All Time.csv` 

После предобработки удалены:
- пустые строки,
- столбцы `Date of Birth`, `Place of Birth`,
- строки, где хотя бы одна из наград/номинаций равна 0 (т.е. только актёры с ненулевыми показателями).
